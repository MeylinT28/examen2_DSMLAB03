## Descripción

ViajaSV es una aplicación móvil desarrollada para gestionar destinos turísticos.

La aplicación permite:

- Registrar usuarios e iniciar sesión.
- Crear destinos turísticos.
- Visualizar destinos.
- Editar destinos.
- Eliminar destinos con confirmación.
- Seleccionar imágenes desde la galería.
- Registrar país, precio y descripción.
- Validar los datos ingresados.

## Tecnologías utilizadas

- Kotlin
- Android Studio
- Firebase Authentication
- Cloud Firestore
- RecyclerView
- CardView
- Glide
- Material Design

## Funcionalidades

### Login
Registro e inicio de sesión utilizando Firebase Authentication.

### Gestión de destinos
La aplicación permite realizar las operaciones CRUD:

- Crear
- Leer
- Actualizar
- Eliminar

### Imágenes
Las imágenes de los destinos se seleccionan desde la galería del dispositivo y se almacenan localmente.

### Validaciones
El formulario valida que:

- Los campos obligatorios no estén vacíos.
- El precio sea mayor que cero.
- La descripción tenga mínimo 20 caracteres.
- Cada destino tenga una imagen.

## Diseño

La aplicación utiliza una paleta de colores basada en Material Design, con tonos rosados y azules, además de un ícono personalizado relacionado con viajes.
